# PCB设计与仿真：嘉立创EDA专业版入门

## 一、课程定位

本课程面向机器人社团新成员和电子设计初学者，以“传感器信号的RC低通滤波”为案例，建立需求、仿真、工程原理图、封装、PCB、设计检查和制造资料之间的联系。

完整课程建议安排 **4次课，每次90分钟，共6小时**。配套14页PPT是一份约10分钟的入门微课，用于第一次课导入或课程作业试讲；其演示项目应提前准备，完整画板练习在后续实操课完成。

- **授课形式**：教师演示、分步实操、两人互查、个人提交。
- **课程成果**：RC仿真记录、工程原理图、双层PCB、检查记录、制造文件复核记录。
- **课程主线**：先预测，再验证，再落实到PCB。

## 二、为什么开设这门课

社团成员常能识别电子元件，却不清楚原理图中的连接如何转化为电路板；也可能将“仿真正常”“DRC通过”直接当成成品可靠的证明。本课用器件数量少、结果可以计算的RC电路，让新成员先理解每个环节的职责，再逐步学习软件操作。

对机器人社团而言，本课可作为传感器接口板、电源监测板和控制板设计的前置训练。课程使用统一的命名、参数核对、互查与提交规则，便于后续团队项目复用。

## 三、授课对象与前置基础

### 对象

机器人社团新成员、第一次接触PCB设计的学生。无需已有PCB经验。

### 必需基础

1. 认识电阻、电容、地和电压源的符号。
2. 能使用欧姆定律，理解电压、电流及单位。
3. 了解串联、并联和网络连接，能辨认同一节点。
4. 会进行基本电脑操作、保存文件和整理项目文件夹。

频率响应、分贝、时间常数由课程解释，不作为课前必须掌握的内容。

### 差异化支持

- **基础较弱**：提供元件符号速查、参数单位表、部分完成的工程及逐步任务单；每次先完成“必做”任务。
- **基础一般**：独立完成RC仿真与PCB，说明关键布局决定。
- **已有经验**：研究负载、源阻抗、元件容差对滤波的影响，或比较不同布局；增加内容须建立在基础交付完成之后。

## 四、学习目标

完成课程后，学生应能：

1. 按顺序说明需求、仿真、原理图与封装、PCB、检查与导出的工作流程。
2. 根据给定R、C计算理想截止频率，并在仿真结果中定位相应频率和增益。
3. 区分仿真模型的电气行为与PCB封装的物理信息，核对网络、参数及引脚映射。
4. 完成一块简单双层RC滤波PCB的板框、布局、布线与GND铜区设置。
5. 依据项目规则执行DRC，并进行功能、装配、丝印和制造资料的人工复核。
6. 提交具有可追溯文件和说明的课程项目，向同伴解释至少一个设计决定。

## 六、主案例与技术边界

### RC低通电路

输入经电阻R连接到输出节点；电容C接在输出节点与GND之间，输出测量跨接电容。

| 参数 | 教学设定 |
| --- | --- |
| R | 1 kΩ |
| C | 100 nF |
| 输入 | 交流小信号源，示例AC幅值1 V |
| 扫频范围 | 10 Hz–100 kHz，对数扫频 |
| PCB | 双层板；0603电阻、电容作为封装练习示例，实际器件规格逐项核对 |

理想模型：

$$\tau=RC=100\,\mu s$$

$$f_c=\frac{1}{2\pi RC}\approx1591.55\,Hz$$

$$|H(j\omega)|=\frac{1}{\sqrt{1+(2\pi fRC)^2}},\qquad G_{dB}=20\log_{10}|H|$$

| 观察点 | 理想幅度比 | 理想增益 |
| --- | ---: | ---: |
| 100 Hz | 约0.998 | 约−0.017 dB，接近0 dB |
| 1.59 kHz | 约0.707 | 约−3.01 dB |
| 10 kHz | 约0.157 | 约−16.07 dB |

以上是课堂给定参数的理论计算，**不是已运行嘉立创EDA得到的仿真结果或实物测量值**。PPT中的软件截图用于说明官方操作入口；PCB布局和布线图是教学示意，没有执行软件DRC。

### 实作时保持的边界

1. 仿真图页使用具备仿真模型的器件；工程原理图使用已核对封装的可制造器件。此课采用分别建立两类图页、核对相同网络和参数的方式，不假定仿真器件可以直接制造。
2. 仿真模型、符号引脚和封装焊盘是不同信息，应逐个核对映射。
3. 理想RC推导未包含全部源阻抗、负载及器件容差影响；真实应用须评估这些因素。
4. 铺铜应选择正确的层和网络，修改后重建；铺铜不自动证明接地质量。
5. DRC通过只说明当前检查规则未报告相关问题，不证明电路功能、全部制造条件或装配可靠性。
6. 不套用固定线宽、间距和板边距离；按实际电路需求及制造商当前能力设置规则。

## 七、完整实操课安排

### 第一次课：读电路与建立仿真（90分钟）

| 时间 | 活动 | 验收证据 |
| --- | --- | --- |
| 0–10分钟 | 14页微课导入，介绍软件界面并展示流程与最终项目形态 | 学生说出流程中的至少三个环节 |
| 10–25分钟 | 识别RC拓扑，计算时间常数与截止频率 | 手写或电子计算记录 |
| 25–40分钟 | 演示新建NGSpice仿真图页、放置R/C、源与地 | 学生完成电路连接 |
| 40–65分钟 | 放置输入输出探针，配置AC分析并运行 | 自己生成的波形截图和设置记录 |
| 65–80分钟 | 在三个观察点比较理论与仿真，解释单位 | 带频率与增益单位的结果记录 |
| 80–90分钟 | 排错与退出检查，保存项目 | 电路、参数和分析设置可重新打开 |

**必做**：电路连接、AC设置、三个观察点记录。**提高**：观察阶跃响应，解释时间常数。教师演示必须在课前真实运行；如现场软件异常，使用标明来源的教师预录演示，学生课后补做。

### 第二次课：工程原理图与封装（90分钟）

| 时间 | 活动 | 验收证据 |
| --- | --- | --- |
| 0–10分钟 | 回顾仿真结果，辨认模型与封装 | 完成两者职责对照 |
| 10–35分钟 | 新建工程原理图，选择R/C及输入输出接口 | 位号与网络命名清楚 |
| 35–55分钟 | 检查值、封装、焊盘编号与符号引脚 | 器件清单与封装核对记录 |
| 55–75分钟 | 原理图转PCB，确认导入变更和飞线 | PCB中出现正确器件与网络 |
| 75–90分钟 | 两人互查，练习原理图修改后同步 | 互查签名或记录，文件已保存 |

**必做**：网络与参数一致、封装已指定、引脚映射正确。**提高**：比较另一种封装的尺寸与焊接便利性，并说明选择理由。

### 第三次课：布局、布线与铺铜（90分钟）

| 时间 | 活动 | 验收证据 |
| --- | --- | --- |
| 0–15分钟 | 设置双层铜层与闭合板框，确定接口约束 | 板框、层和接口位置已确认 |
| 15–40分钟 | 按输入→R→输出布局，C靠近输出节点 | 布局截图及一句理由 |
| 40–65分钟 | 完成信号与地连接，检查剩余飞线 | 网络完整，走线不明显绕行 |
| 65–80分钟 | 建立GND铜区，设置层和网络，重建 | 铜区与GND连接检查记录 |
| 80–90分钟 | 同伴检查焊接空间与标注，保存版本 | 修改前后记录与项目版本 |

**必做**：连接正确、板框闭合、铜区网络明确。**提高**：在保留网络正确性的条件下优化布局，并比较两版的连接路径。

### 第四次课：检查、导出与说明（90分钟）

| 时间 | 活动 | 验收证据 |
| --- | --- | --- |
| 0–20分钟 | 核对制造要求与项目规则，运行DRC | DRC记录；问题已修复或有合理说明 |
| 20–40分钟 | 人工检查引脚、接口、方向、丝印与空间 | 完成检查清单 |
| 40–55分钟 | 导出Gerber与钻孔文件，预览核对 | 层、板框、钻孔复核记录 |
| 55–75分钟 | 每人简短介绍一个设计决定，同伴提问 | 设计说明与反馈 |
| 75–90分钟 | 修改C=220 nF，预测后仿真；整理最终提交 | 新截止频率结果与项目归档 |

**必做**：完整提交、可复核检查记录、解释一个设计决定。**提高**：选做制造与实物验证，比较理论、仿真与测量差异。

## 九、评价与验收

以下为本课程设计的评分规则，满分100分。

| 项目 | 分值 | 达标条件 |
| --- | ---: | --- |
| 电路理解与理论预测 | 20 | 拓扑正确，fc与单位正确，能解释截止点 |
| 仿真设置与结果记录 | 20 | 引擎、参数、分析与探针明确，有学生自己生成的结果 |
| 原理图与封装 | 20 | 网络和参数一致，器件封装与引脚映射经过核对 |
| PCB布局与连接 | 20 | 接口与信号路径清楚，网络完整，铜区设置正确 |
| 检查、文件与说明 | 20 | DRC及人工复核记录完整，制造资料可检查，能解释设计决定 |

**关键验收项**：网络错误、封装引脚映射错误、未核对的制造资料，应先修正再提交；这些问题不能仅用总分平均掩盖。

### 提交清单

1. 工程源文件或可访问的工程链接，以及所用软件版本说明。
2. 工程原理图PDF或截图、器件和封装清单。
3. 仿真参数与结果记录：三个观察点、理论比较、异常原因说明。
4. PCB顶层/底层或2D/3D截图，简短布局说明。
5. DRC结果、人工复核清单、修改记录。
6. 导出的Gerber和钻孔文件，以及对应预览检查记录。
7. README：案例参数、目录、完成程度、已知问题、复现步骤、参考资料。

可按“仿真 / 原理图 / PCB / 制造文件 / 检查记录 / README”组织个人仓库。本仓库提供教学大纲和课件，不包含学生已完成的EDA工程。

## 十、社团开展与资源支持

- **项目选择**：首轮统一RC滤波板，降低排错复杂度；完成后按小组兴趣延伸至传感器接口等项目。
- **组织支持**：社团统一教师示例、器件清单、规则检查表和提交规范；安排有经验成员担任助教，集中回答常见问题。
- **设备支持**：优先使用已有电脑和仪器；分组共享测量设备，避免要求每位新成员购买仪器。
- **过程支持**：第一次课完成仿真、第二次课完成封装检查、第三次课完成连线、第四次课完成交付，每阶段保留可恢复版本。
- **后续迭代**：收集报错类型与学生反馈，更新任务单；保留优秀项目的设计说明作为下一轮参考，引用与复用须保留来源。

## 十一、可能遇到的问题与相应解决方案

课程实施中重点关注以下五类问题，按具体工程和课堂条件选择处理措施。

| 问题类别及表现 | 相应解决方案 | 验收标准 |
| --- | --- | --- |
| **1. 学习基础与课堂进度**：部分学生不熟悉电路连接和参数单位，操作进度差异较大 | 课前诊断基础，提供符号与单位速查表；演示按小任务拆分，设置必做与提高任务；两人轮换操作，助教重点帮助进度落后的学生 | 每人完成必做任务，能说明RC连接与参数含义，并解释一个设计决定 |
| **2. 软件环境与资源条件**：登录、版本或仿真引擎异常，电脑或仪器不足 | 教师课前验证软件版本、引擎和示例工程；现场异常时用教师预录演示辅助讲解，安排学生补做；电脑可分组轮换，实物验证作为具备条件后的扩展 | 学生能打开工程并运行案例；个人操作证据齐全，基础交付可在现有条件下完成 |
| **3. 仿真设置与结果理解**：无有效曲线，或结果与理论预期不符 | 按“模型与接地→R/C参数和单位→交流源→探针→AC设置”的顺序排查；记录三个观察点，区分电压、幅度比与dB，结合源阻抗和负载解释差异 | 仿真可重复运行，读数与单位明确，能解释截止点及偏差原因 |
| **4. 原理图与PCB设计**：封装映射、网络同步或布线铺铜出现错误 | 逐个核对器件、封装和引脚；原理图修改后核对导入变更；检查剩余飞线、铜层和GND网络，修改后重建铺铜并复查 | 原理图与PCB参数、网络一致，封装映射正确，必需连接完整 |
| **5. 检查与文件交付**：忽略DRC问题，或制造文件、版本记录不完整 | 按制造要求设置规则并处理报错，配合人工复核；核对铜层、阻焊、丝印、板框和钻孔；保存最终版本，按统一目录提交，由同伴检查能否打开与复现 | 无未处理的关键错误，制造文件与最终工程对应，检查记录及复现说明完整 |

课堂按“学生自查→同伴互查→助教协助→修改后复验”处理问题；仍未解决的故障登记后安排补做。学生在已有检查记录中保留一项典型问题及处理结果，教师据此改进下一轮任务单。
