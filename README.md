# 机器人社团内训资料：PCB设计与仿真

本仓库用于教学部招新考核，收录《PCB设计与仿真：嘉立创EDA专业版入门》的课程大纲与授课课件。课程面向机器人社团新成员及电子设计初学者，以RC低通滤波电路为案例，介绍仿真、原理图、封装、PCB设计、检查与制造文件之间的联系。

完整课程规划为4次课，每次90分钟；配套课件共14页，用于约10分钟的入门讲解。

## Git与GitHub使用记录

### 1. 你在本次任务中使用了哪些Git或GitHub功能？

本次使用GitHub创建公开远程仓库，再通过`git clone`克隆到本地，按`topic/`、`slides/`和`assets/`整理资料。使用`git add`暂存文件、`git commit`记录修改、`git push`将提交推送到GitHub，并通过`git status`、`git log`及远程分支检查确认上传结果。

前两次提交分别为“添加PCB设计与仿真内训选题”和“添加14页授课课件、PDF、讲稿及可编辑图形素材”；README在后续单独补充。这样可以区分课程选题、课件交付和说明文档的修改过程。本次直接在`main`分支完成提交，尚未使用Pull Request。

### 2. 操作过程中遇到了哪些问题？你是如何解决的？

- **远程推送需要身份认证。** 首次在禁止交互认证的模式下推送失败，之后通过Git Credential Manager提供的浏览器登录流程完成授权，再次推送成功。
- **本地存在多个版本，容易上传旧课件。** 根据最终确认的14页版本整理提交文件，核对PPTX、PDF和讲稿的文件哈希，并检查本地提交与远程`main`分支是否一致。
- **课程内容需要多次调整。** 制作者提出将工具改为嘉立创EDA专业版、增加软件操作介绍、将问题与解决方案精简为五类，以及删除大纲中的官方资料参考部分；据此修改对应材料，再整理入库。

### 3. 如果将来需要多名教学部成员共同维护这个仓库，你认为应当如何组织文件与修改流程？

文件按课程主题组织：大纲放在`topic/`，课件、PDF及讲稿放在`slides/`，图片和图形源文件放在`assets/`。课程数量增加后，可在各目录下建立同名的课程子目录，并统一文件命名，方便对应查找。

修改前先拉取最新版本，按具体任务创建分支，例如`update/pcb-course`。每次提交围绕一个明确修改点，并在提交说明中写清内容。完成后通过Pull Request说明修改原因和影响，由另一名成员检查知识点、教学安排、文件链接及课件显示效果，确认后合并到`main`。

PPTX和PDF不便直接合并，应明确每份课件的当前编辑负责人，避免多人同时修改同一文件；更新课件时同步更新PDF、讲稿和相关素材。待讨论的问题可记录在Issues中，分配负责人并跟踪处理结果。
